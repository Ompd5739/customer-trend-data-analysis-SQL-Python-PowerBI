# customer-trend-data-analysis-SQL-Python-PowerBI


## 📌 Project Overview

This project presents an end-to-end **Customer Shopping Behavior Analysis** workflow using **Python, PostgreSQL/SQL, and Power BI**.

The project analyzes transactional data from **3,900 customer purchases** across different product categories. The objective is to understand customer spending patterns, customer segments, product preferences, discount behavior, shipping preferences, and subscription behavior, and convert these findings into useful business recommendations.

## 🎯 Objectives

- Analyze customer shopping and spending behavior.
- Clean and prepare the dataset using Python.
- Store and analyze cleaned data in PostgreSQL.
- Answer business questions using SQL queries.
- Build an interactive Power BI dashboard.
- Generate actionable business recommendations.

## 🗂️ Dataset

- **Rows:** 3,900
- **Columns:** 18
- **Missing values:** 37 values in the `Review Rating` column.

### Key Features

**Customer Demographics**
- Age

**Purchase Details**
- Item Purchased

**Shopping Behavior**
